# AGENTS 模板套用提示词

配合本仓库的 [`AGENTS.zh-CN.md`](../AGENTS.zh-CN.md) 使用：新项目 / 接管旧项目时，把对应那段整段复制发给 AI 即可。

## 新项目，可粘贴

```
以本仓库的 AGENTS.zh-CN.md 为骨架为这个新项目生成 AGENTS.md：
只填项目槽位（闸门命令真源位置、技能映射、项目特有红线），骨架的规则与判据原样保留，不要重写、不要新增流程。
同时建好它依赖的文件：README（含「常用命令」一节）、docs/00-产品方向.md、.gitignore。
所有路径与命令必须真实存在，拿不准就来问我，不许编。
台阶 0 用 grilling 技能（一轮问题那种）代替 grill-me。
```

## 接管旧项目，可粘贴

```
以本仓库的 AGENTS.zh-CN.md 为基准，为这个仓库产出 AGENTS.md。流程：
1) 先只勘察不写文件：git 状态、语言/包管理与锁文件、真实可用的 lint/format/test/CI 命令（逐条确认，跑不通的说明原因）、现有文档、是否已有 AGENTS.md / CLAUDE.md / .cursor / 嵌套规则文件。
2) 给我一份差异清单：哪些命令/路径要替换成真实的；哪些条款现状不满足（标为「目标」+ 渐进计划）；哪些既有规则要合并；哪里与模板冲突。
3) 我确认后再落盘：AGENTS.md（根目录，≤70 行）+ README「常用命令」节 + docs/00-产品方向.md 指针，合并而非覆盖既有规则，命令先验证再写。
```
